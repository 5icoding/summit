## 6. 迁移规划（Migration Plan）

### Phase 1 — MVP 已完成（2026 Q1）✅

**技术演进**：Vue 3 SPA + Express REST API + MySQL 本地部署

**交付物**：
- 7 领域 36 维度 324 水平描述数据库
- PBL 项目库（36 个认证项目）
- 公开 PBL 汇总（36 个项目 + 36 维能力维度映射）
- 参考文献库（60 条，含中文标题）
- PBL 详情页（树形指导结构 + 折叠面板）
- 数据采集工具链（Playwright + Node.js 脚本）

---

### Phase 2 — 用户系统（2026 Q2）

**目标**：支持用户注册、登录、个人收藏

**技术变更**：

| 组件 | 变更内容 |
|------|----------|
| 后端 | 新增 `/api/auth` 路由（注册/登录/刷新 Token） |
| 数据库 | 新增 `users`、`user_favorites` 表 |
| 认证 | JWT（jsonwebtoken）+ bcrypt 密码哈希 |
| 前端 | 新增登录/注册页，Axios 拦截器自动附 Token |
| 测试 | 新增 API 集成测试（Jest + Supertest） |

**架构变化**：
```
新增组件：用户认证服务（Auth Service）
新增中间件：JWT 验证中间件（authMiddleware）
新增数据实体：users, user_favorites, user_history
```

---

### Phase 3 — 内容扩展（2026 Q3）

**目标**：扩充项目内容，支持本土 PBL 案例录入

**技术变更**：

| 组件 | 变更内容 |
|------|----------|
| 后端 | 新增内容管理 API（/api/admin/*） |
| 前端 | 新增管理后台（Admin Portal，独立路由） |
| 数据库 | 新增内容审核状态字段，支持草稿/发布 |
| 存储 | 引入云对象存储（OSS）存储 PBL 附件 |

---

### Phase 4 — 云端部署（2026 Q3）

**目标**：迁移至云端，支持多用户并发访问

**技术变更**：

| 组件 | 变更内容 |
|------|----------|
| 服务器 | 云服务器（ECS）+ Nginx 反向代理 |
| 进程管理 | PM2 集群模式（多核利用） |
| 数据库 | MySQL RDS（托管，自动备份） |
| 前端 | Vite 构建 → Nginx 静态文件服务 / CDN |
| SSL | HTTPS 证书（Let's Encrypt） |
| 监控 | morgan 请求日志 + 告警通知 |
| CI/CD | GitHub Actions 自动构建部署 |

**部署架构图（目标）**：
```
用户 → CDN → Nginx（HTTPS:443）
              ├── /          → 静态文件（Vue dist/）
              └── /api/*    → Node.js（PM2 cluster）→ MySQL RDS
```

---

### Phase 5 — 社区功能（2026 Q4）

**目标**：支持教师分享资源、评论、协作

**技术变更**：

| 组件 | 变更内容 |
|------|----------|
| 后端 | 新增评论、分享、通知 API |
| 数据库 | 新增 `comments`、`shares`、`notifications` 表 |
| 缓存 | Redis 缓存热点数据（框架数据、排行榜） |
| 实时 | 引入 WebSocket（Socket.io）推送通知 |

---

### Phase 6 — AI 智能功能（2027 Q2）

**目标**：基于核心素养框架智能推荐 PBL 项目

**技术变更**：

| 组件 | 变更内容 |
|------|----------|
| AI 服务 | 调用 Claude API（LLM）实现语义推荐 |
| 向量数据库 | 引入 pgvector / Pinecone 存储维度嵌入向量 |
| 前端 | 新增 AI 推荐面板，自然语言查询入口 |
| 数据 | 维度描述文本向量化（Embedding） |

**推荐逻辑**：
```
用户输入教学目标
    → LLM 提取能力维度关键词
    → 向量相似度匹配 PBL 项目
    → 排序输出推荐列表 + 匹配理由
```

## 8. 实施治理（Implementation Governance）

### 8.1 架构变更控制

- 所有架构变更须更新对应 EA-00X 文档
- 数据库结构变更须同步更新 `sql/` 目录下的 DDL 脚本
- API 接口变更须更新 EA-004 接口规范，并通知前端
- 重大架构决策记录于本文件 §7（架构决策日志）

### 8.2 版本兼容性原则

- REST API 新增字段时保持向后兼容（现有字段不删减）
- 数据库字段新增时使用 `ALTER TABLE ADD COLUMN`，不破坏现有数据
- 路由变更遵循 `/v2/` 版本前缀策略（Phase 3+）
