## 3. 前端应用组件清单（Frontend Component Catalogue）

### 3.1 应用外壳

| 组件 | 文件路径 | 职责 |
|------|----------|------|
| App 根组件 | `src/App.vue` | 挂载 `<MainLayout>`，RouterView 入口 |
| 应用外壳 | `src/layout/MainLayout.vue` | 侧边栏 + 顶部导航 + 面包屑 + 页面过渡动画 |

**MainLayout 核心机制：**
- 侧边栏：宽度 220px，可折叠至 64px，折叠时标签/徽章淡出隐藏
- 顶部栏：高度 56px，显示面包屑（`route.meta.title`）
- 页面过渡：`page-fade`（opacity 0.2s）

### 3.2 页面组件（Route-Level Components）

| 页面 | 路由 | 文件 | 核心 API 调用 |
|------|------|------|--------------|
| 首页 | `/` | `HomePage.vue` | `getDomains()`, `getStats()` |
| 核心素养框架 | `/framework` | `FrameworkPage.vue` | `getDomainsFull()` |
| 维度详情 | `/dimension/:id` | `DimensionPage.vue` | `getDimension(id)` |
| 参考课标 | `/curriculum` | `CurriculumPage.vue` | `getDomainsFull()` |
| PBL 项目库 | `/pbl` | `PblPage.vue` | `getPblProjects(params)`, `getPblStats()` |
| PBL 项目详情 | `/pbl/:id/detail` | `PblDetailPage.vue` | `getPblProject(id)`, `getPblInstructions()` |
| 公开PBL项目 | `/pbl-open` | `PblOpenPage.vue` | `getPblOpen(params)`, `getPblOpenStats()` |
| 参考文献 | `/references` | `ReferencesPage.vue` | `getReferences(params)`, `getReferencesStats()` |

## 4. 后端应用组件清单（Backend Component Catalogue）

### 4.1 服务入口

| 组件 | 文件 | 职责 |
|------|------|------|
| 主入口 | `index.js` | Express 应用初始化、中间件注册、路由挂载、端口监听 |
| 数据库连接池 | `db.js` | mysql2 连接池，10 个连接，promise-based |

### 4.2 路由模块

#### domains.js — 能力领域路由
| 端点 | 方法 | 描述 | 关键逻辑 |
|------|------|------|----------|
| `/api/domains/full` | GET | 完整嵌套数据 | 4 次 JOIN 查询 + 内存组装树形结构 |
| `/api/domains` | GET | 领域列表 | 简单查询 |
| `/api/domains/:id/dimensions` | GET | 领域下维度 | WHERE domain_id |

**设计注意**：`/full` 端点在内存中组装嵌套结构（非 SQL JOIN），避免大量冗余数据传输。

#### dimensions.js — 能力维度路由
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/dimensions/:id` | GET | 单维度详情（含水平列表） |
| `/api/dimensions/stats/summary` | GET | 汇总统计 |

#### pbl.js — PBL 项目路由
| 端点 | 方法 | 描述 | 关键逻辑 |
|------|------|------|----------|
| `/api/pbl` | GET | 项目列表 | 动态 SQL WHERE 拼接（category/grade/certified） |
| `/api/pbl/stats/overview` | GET | 统计数据 | 多查询并行聚合 |
| `/api/pbl/instructions` | GET | 树形指导结构 | LEFT JOIN sample，内存过滤 parent/child |
| `/api/pbl/:id` | GET | 单项目详情 | SELECT * |

**路由顺序约束**：`/stats/overview` 和 `/instructions` 必须在 `/:id` 之前注册，否则被 Express 参数路由拦截（已知 Bug，已修复）。

#### references.js — 参考文献路由
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/references` | GET | 文献列表（type/link_type/keyword 过滤，keyword 匹配 title+title_zh） |
| `/api/references/stats` | GET | 统计分布 |
| `/api/references/:id` | GET | 单条详情 |

#### pbl_open.js — 公开 PBL 路由
| 端点 | 方法 | 描述 |
|------|------|------|
| `/api/pbl-open` | GET | 公开项目列表（多维筛选） |
| `/api/pbl-open/stats` | GET | 按学科/认证统计 |
| `/api/pbl-open/:id` | GET | 单项目详情 |

## 5. 关键设计决策（Key Design Decisions）

| 决策 ID | 决策内容 | 理由 |
|---------|----------|------|
| ADD-01 | 前后端完全分离，独立端口（5173/3000） | 开发效率，可独立部署 |
| ADD-02 | 不引入状态管理库（Pinia/Vuex） | 页面粒度小，本地 ref/reactive 足够，降低复杂性 |
| ADD-03 | `/domains/full` 返回全量嵌套 JSON | FrameworkPage 一次请求获取全部框架数据，无需二次请求 |
| ADD-04 | 动态 SQL 拼接（而非 ORM） | 轻量灵活，适合小团队快速迭代，查询可读性高 |
| ADD-05 | 路由顺序：具体路径优先于参数路由 | 避免 `/stats/overview` 被 `/:id` 拦截 |
| ADD-06 | PblDetailPage 左侧固定目录，右侧只渲染当前章节 | 优化性能，大文本不全量渲染 |
| ADD-07 | 搜索采用 appliedKeyword（点击/回车触发） | 避免实时过滤影响输入体验 |
| ADD-08 | 弹窗（Modal）而非路由跳转展示列表详情 | 保留列表上下文，减少页面切换成本 |

## 6. 应用接口规范（API Interface Specification）

### 6.1 通用约定

- **协议**：HTTP 1.1
- **数据格式**：JSON（Content-Type: application/json）
- **字符编码**：UTF-8
- **错误响应格式**：`{ "error": "<错误描述>" }`
- **HTTP 状态码**：200（成功），404（未找到），500（服务器错误）
- **CORS**：全域开放（cors() 默认配置，开发阶段）

### 6.2 列表接口过滤参数规范

| 参数名 | 类型 | 匹配方式 | 示例 |
|--------|------|----------|------|
| `category` | string | = 精确匹配 | `category=Science` |
| `grade` | string | LIKE 模糊匹配 | `grade=高中` |
| `certified` | boolean | = 精确匹配 | `certified=1` |
| `keyword` | string | LIKE 双字段匹配 | `keyword=生物` |
| `type` | string | = 精确匹配 | `type=书` |
| `link_type` | string | = 精确匹配 | `link_type=url` |

### 6.3 嵌套响应示例（/api/domains/full）

```json
[
  {
    "id": 1,
    "name": "文本分析（精读）",
    "sort_order": 1,
    "dimensions": [
      {
        "id": 1,
        "name": "主题与中心思想",
        "description": "...",
        "curriculum": { "language": 1, "social": 0, "science": 1 },
        "levels": [
          { "level": 0, "description": "..." },
          { "level": 1, "description": "..." },
          ...
        ]
      }
    ]
  }
]
```
