## 3. 技术组件规格（Technology Component Specifications）

### 3.1 前端技术规格

| 组件 | 版本 | 用途 | 选型理由 |
|------|------|------|----------|
| Vue 3 | 3.x | UI 框架 | Composition API 灵活性高，国内生态成熟 |
| Vite | 5.x | 构建工具 | 冷启动快（ESM），HMR 极速，Vue 官方推荐 |
| Vue Router | 4.x | 客户端路由 | Vue 3 官方路由，HTML5 History 模式 |
| Axios | 1.x | HTTP 客户端 | 拦截器支持，Promise API，超时配置 |
| CSS Scoped | — | 样式隔离 | 组件级样式隔离，无额外依赖 |

**无全局状态管理库**：每个页面组件使用 `ref`/`reactive` 管理本地状态，足以满足当前 MVP 需求。

### 3.2 后端技术规格

| 组件 | 版本 | 用途 | 选型理由 |
|------|------|------|----------|
| Node.js | LTS | 运行时 | JS 全栈统一，生态丰富 |
| Express.js | 5.x | Web 框架 | 轻量灵活，Router 分模块组织 |
| mysql2 | 3.x | 数据库驱动 | 原生 Promise 支持，连接池管理 |
| cors | — | 跨域中间件 | 开发阶段全域开放，简化前后端联调 |
| dotenv | — | 环境变量 | .env 文件隔离配置，不入代码库 |
| nodemon | 3.x | 开发热重载 | 文件变更自动重启，提升开发效率 |

### 3.3 数据库规格

| 配置项 | 值 |
|--------|-----|
| 数据库引擎 | MySQL 8.x |
| 数据库名 | Summit |
| 字符集 | utf8mb4 |
| 排序规则 | utf8mb4_unicode_ci |
| 连接池大小 | 10 connections |
| 连接方式 | TCP/IP（localhost） |
| 用户 | root |
| 端口 | 3306（默认） |

## 4. 部署拓扑（Deployment Topology）

### 4.1 当前状态：本地开发环境

```
开发者工作站（Windows 11）
│
├── 前端进程
│   命令：cd frontend && npm run dev
│   地址：http://localhost:5173
│   工具：Vite Dev Server
│
├── 后端进程
│   命令：cd backend && npm run dev
│   地址：http://localhost:3000
│   工具：nodemon → node index.js
│
└── 数据库进程
    地址：localhost:3306
    工具：MySQL 8.x（本地安装）
    数据库：Summit
```

**进程依赖关系：**
```
MySQL ← 后端（pool.getConnection）← 前端（Axios HTTP）← 浏览器
```

### 4.2 目标状态：云端生产环境（Phase 2+ 规划）

```
用户浏览器
    │ HTTPS
    ↓
CDN（静态资源）
    │
    ├── 前端 SPA（Vite Build → dist/）
    │   托管于：云存储 / Nginx 静态服务
    │
    └── 后端 API 服务器
        Nginx 反向代理 → Node.js 集群（PM2）
            │
            └── MySQL（RDS 托管）

环境变量管理：云端密钥服务 / 配置中心
```

## 6. 安全考量（Security Considerations）

### 6.1 当前状态（MVP）

| 风险项 | 当前状态 | 风险等级 |
|--------|----------|----------|
| 数据库密码 | 存于 `.env`，不入 Git | 中（本地部署） |
| CORS | 全域开放 | 高（需生产限制） |
| SQL 注入 | 参数化查询（`?` 占位符）| 低 |
| XSS | Vue 模板自动转义 | 低 |
| 无身份认证 | 所有接口公开 | 高（内容公开可接受） |
| HTTPS | 无 | 高（生产必须启用） |

### 6.2 Phase 2 安全改进项

1. 启用 HTTPS（SSL/TLS 证书）
2. CORS 白名单配置（仅允许前端域名）
3. 引入 JWT 身份认证（用户系统前置）
4. 数据库最小权限原则（创建专用账号，限制 DDL 权限）
5. Rate Limiting（防止 API 滥用）
6. Helmet.js（HTTP 安全头）

## 7. 技术标准与规范（Technical Standards）

### 7.1 编码规范

| 规范项 | 标准 |
|--------|------|
| JavaScript 版本 | ES2020+（Node.js LTS 支持） |
| 模块系统（后端） | CommonJS（`require`/`module.exports`） |
| 模块系统（前端） | ES Modules（`import`/`export`） |
| Vue 组件风格 | Composition API + `<script setup>` |
| CSS 方式 | Scoped Style（不引入 Tailwind/UI 库） |
| 字符集 | UTF-8（源码）/ utf8mb4（数据库） |

### 7.2 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| 数据库表 | snake_case | `capability_domain` |
| 数据库字段 | snake_case | `sort_order`, `name_zh` |
| Vue 组件文件 | PascalCase | `PblDetailPage.vue` |
| Vue 组件名 | PascalCase | `MainLayout` |
| JS 变量/函数 | camelCase | `getPblProjects`, `appliedKeyword` |
| CSS 类名 | kebab-case | `.menu-item`, `.proj-header` |
| API 路由路径 | kebab-case | `/pbl-open`, `/stats/overview` |

## 9. 技术风险评估（Technical Risk Assessment）

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| Google Translate API 非官方，可能失效 | 中 | 中 | 切换 DeepL API 或 OpenAI 翻译 |
| MySQL 本地单点，无高可用 | 高 | 高 | 生产阶段迁移 RDS |
| 无缓存层，/domains/full 每次全量查询 | 中 | 低（小数据量） | 引入内存缓存（node-cache） |
| CORS 全开，存在安全风险 | 低（内网）| 高（上线后）| 生产限制白名单 |
| 无日志系统，问题难以排查 | 高 | 中 | 引入 morgan 请求日志 |
| 无单元测试 | 高 | 中 | Phase 2 补充 API 集成测试 |
