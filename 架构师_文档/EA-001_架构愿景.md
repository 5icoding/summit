## 3. 商业背景与驱动力（Business Context & Drivers）

### 3.1 战略背景

萨米特学习法（Summit Learning）源自美国 Summit Public Schools，以核心素养为中心，构建 7 大能力领域、36 个能力维度、9 级水平（0–8 级）的完整评估体系。当前国内尚无系统化、中文化的萨米特核心素养数字平台，存在显著市场空白。

### 3.2 政策驱动力

- **双减政策**：减少学科刷题，转向素养与能力培养
- **新课标改革**：语文/社会/科学课标强调跨学科能力
- **新高考导向**：项目制学习（PBL）逐步纳入综合素质评价

### 3.3 核心问题陈述

> 国内教师与教育研究者缺乏一个**可检索、中文化、结构化**的萨米特素养资源库，无法高效将国际 PBL 框架本土化应用于教学实践。

---

## 4. 架构愿景陈述（Architecture Vision Statement）

> **打造中国领先的萨米特核心素养数字平台，系统呈现 7 大能力领域、36 个维度与 PBL 项目库，赋能教师将国际顶尖素养评估框架融入本土教学。**

## 7. 架构原则（Architecture Principles）

| 编号 | 原则 | 说明 |
|------|------|------|
| P-01 | **数据完整性优先** | 素养框架数据来源权威，录入须与原版一致 |
| P-02 | **中文化本土适配** | 所有用户界面与内容以简体中文为主，英文辅助 |
| P-03 | **前后端分离** | 前端 SPA 通过 REST API 与后端解耦，独立部署 |
| P-04 | **渐进式扩展** | 数据模型与 API 设计预留扩展字段，避免破坏性变更 |
| P-05 | **最小依赖原则** | 优先使用轻量成熟库，避免引入大型框架增加复杂性 |
| P-06 | **单一数据源** | 所有业务数据存于 MySQL，不允许前端持久化业务状态 |

## 8. 约束条件（Constraints）

| 类型 | 约束 |

| 技术 | 数据库使用 MySQL；前端使用 Vue 3；后端使用 Node.js/Express |

| 人员 | 小型团队，单人架构+开发模式 |
| 时间 | MVP 已完成，Phase 2 目标 Q2 2026 |
