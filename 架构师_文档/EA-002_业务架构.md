# EA-002 · 业务架构文档（Business Architecture）
**TOGAF ADM Phase B** · 2026-03-21 · v1.0

## 1. 文档目的

本文档依据 TOGAF ADM Phase B 要求，描述萨米特核心素养平台的业务架构，包括业务能力、业务流程、业务角色与信息流，为应用架构与数据架构提供业务基础。

```
萨米特核心素养平台
├── 知识管理能力
│   ├── 素养框架管理（7领域 × 36维度 × 9水平）

├── 内容检索能力
│   ├── 多维度筛选（学科/年级/PA类型/认证状态）
│   ├── 关键词全文检索（中英文双语）

    ├── 框架层级浏览（领域→维度→水平卡片）
    ├── 详情弹窗展示（Modal + 动画）

```

## 4. 核心业务流程（Core Business Processes）

### 4.1 素养框架浏览流程

```
用户访问 /framework
    → 系统加载全量嵌套数据（/api/domains/full）
    → 左侧树形导航展示 7 个领域
    → 用户点击领域节点
    → 右侧展示该领域下 N 个维度的水平卡片（Level 0~8）
    → 用户点击维度跳转至 /dimension/:id
    → 展示水平步进器与课标对应关系
```

### 4.2 PBL 项目检索流程

```
用户访问 /pbl 或 /pbl-open
    → 系统加载统计数据 + 项目列表
    → 用户通过筛选面板设置条件：
        · 年级（单选 6-12）
        · 学科（单选）
        · 认证状态（已认证/全部）
        · 关键词（回车/点击触发）
    → 前端将筛选参数发送至 API
    → 后端动态构建 SQL WHERE 子句返回结果
    → 项目列表实时刷新
    → 用户点击项目行 → 弹出详情 Modal
    → Modal 展示：基本信息/年级/能力维度/链接
    → 可点击「查看详情」跳转至 /pbl/:id/detail
```

### 4.3 参考文献检索流程

```
用户访问 /references
    → 系统加载文献统计 + 文献列表（默认全量）
    → 用户设置筛选条件：
        · 文献类型（书/报告/文章/网站/课程标准）
        · 链接类型（URL/PDF/购书）
        · 关键词（中英文双语匹配）
    → 列表刷新，每行显示中文标题（加粗）+ 英文原标题（灰色）
    → 点击行弹窗：中文标题/作者/出处/链接
```

### 4.4 PBL 详情页浏览流程

```
用户进入 /pbl/:id/detail
    → 顶部项目元数据卡片（名称/学科/学段/时长/认证）
    → 左侧固定目录：5 个章节锚点
        1. 基本信息
        2. 学生任务书 (Student Instructions)
        3. 教师说明书 (Teacher's Guide)
        4. 评分量规 (Rubrics)
        5. 附件
    → 右侧内容区：折叠面板 Accordion
    → 用户点击目录切换章节，右侧只渲染当前章节
    → 支持「展开全部 / 收起全部」操作
```

## 5. 业务信息流（Business Information Flow）

```
外部数据源
    萨米特 XLSX（核心素养.xlsx / 9pbUM.xlsx）
        ↓ 人工导入 + 脚本解析
    MySQL 数据库（Summit）
        ↓ REST API
    Express.js 后端
        ↓ HTTP/JSON
    Vue 3 前端 SPA
        ↓ 浏览器渲染
    最终用户
```
