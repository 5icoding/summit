### UC-001：浏览核心素养框架

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-001 |
| **用例名称** | 浏览核心素养框架 |
| **主参与者** | 访客、教师、研究者 |
| **触发事件** | 用户点击左侧菜单「核心素养框架」|
| **前置条件** | 用户已打开平台网页 |
| **后置条件** | 用户看到7个能力领域及其下属维度 |
| **主成功场景** | 1. 用户点击「核心素养框架」菜单项 <br>2. 系统加载领域与维度数据（/api/domains/full）<br>3. 页面渲染：左侧显示7个能力领域导航 <br>4. 右侧显示当前选中领域的维度卡片列表 <br>5. 用户点击左侧其他领域，右侧内容切换 |
| **扩展场景** | 2a. 网络请求失败：显示错误提示，提供重试按钮 |
| **业务规则** | 领域按 sort_order 升序排列；维度显示名称和简述 |

---

### UC-002：查看能力维度详情

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-002 |
| **用例名称** | 查看能力维度详情 |
| **主参与者** | 访客、教师 |
| **触发事件** | 用户点击某个能力维度卡片 |
| **前置条件** | 用户在核心素养框架页 |
| **后置条件** | 用户看到该维度的0-8级水平描述 |
| **主成功场景** | 1. 用户点击某维度卡片 <br>2. 系统跳转至 /dimension/:id 页面 <br>3. 系统请求维度数据（/api/dimensions/:id）<br>4. 显示维度基本信息（名称、所属领域、课标对应）<br>5. 显示水平步进器（0-8级）<br>6. 用户点击/滑动切换水平等级，右侧更新对应描述 |
| **扩展场景** | 3a. id不存在：显示404提示 |
| **业务规则** | 水平0为最低，8为最高；步进器高亮当前选中水平 |

---

### UC-003：搜索 PBL 项目

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-003 |
| **用例名称** | 搜索与筛选 PBL 项目 |
| **主参与者** | 教师 |
| **触发事件** | 用户在 PBL 项目库页面操作筛选或搜索 |
| **前置条件** | 用户已进入 /pbl 页面 |
| **后置条件** | 列表更新为符合条件的项目 |
| **主成功场景** | 1. 系统加载全部36个PBL项目（/api/pbl）<br>2. 用户选择「学科」（如：语言）<br>3. 系统触发带 category 参数的请求，列表更新 <br>4. 用户输入关键词「Literary」，按回车 <br>5. 系统触发带 keyword 参数的请求，列表更新 <br>6. 用户点击某行，弹出项目详情弹窗 |
| **扩展场景** | 5a. 无匹配结果：显示「暂无相关项目」提示 |
| **业务规则** | 关键词匹配中英文项目名称；筛选条件可叠加 |

---

### UC-004：查看 PBL 项目详情

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-004 |
| **用例名称** | 查看 PBL 项目完整详情 |
| **主参与者** | 教师 |
| **触发事件** | 用户在弹窗中点击「查看详情」按钮 |
| **前置条件** | 用户已在 PBL 项目弹窗中 |
| **后置条件** | 用户看到项目完整内容，包含教学材料 |
| **主成功场景** | 1. 用户点击弹窗内「查看详情 →」按钮 <br>2. 系统跳转至 /pbl/:id/detail <br>3. 系统加载项目基本信息（/api/pbl/:id）<br>4. 系统加载指导结构树（/api/pbl/instructions）<br>5. 左侧显示5章节导航（基本信息/学生任务书/教师说明/量规/附件）<br>6. 默认展示「基本信息」章节 <br>7. 用户点击「学生任务书」，右侧切换至对应章节 <br>8. 用户点击条目标题展开内容，查看详细说明 <br>9. 用户点击「展开全部」一键展开所有条目 |
| **扩展场景** | 3a. 项目不存在：跳转至404页面 |
| **业务规则** | 各章节内容支持独立展开/收起；切换章节时重置折叠状态 |

### UC-005：筛选公开 PBL 项目（含维度查看）

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-005 |
| **用例名称** | 筛选公开PBL项目并查看维度覆盖 |
| **主参与者** | 教师、研究者 |
| **触发事件** | 用户进入「公开PBL项目」页面 |
| **前置条件** | 用户已打开 /pbl-open 页面 |
| **后置条件** | 用户了解某项目覆盖哪些能力维度 |
| **主成功场景** | 1. 系统加载36条公开项目数据 <br>2. 用户点击「科学」筛选学科 <br>3. 列表更新为11个科学类项目 <br>4. 用户点击「11年级」筛选年级 <br>5. 列表进一步筛选 <br>6. 用户点击某项目行 <br>7. 弹窗显示：基本信息、年级标签（适用的高亮）、36维度分7组展示（适用=紫色） <br>8. 用户点击「原始链接」跳转 PARB 页面 |
| **扩展场景** | 2a. 无结果：显示空状态提示 |
| **业务规则** | 适用年级由数据库 grade_6~grade_12 字段决定；维度由 d_* 字段决定 |

### UC-006：搜索参考文献

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-006 |
| **用例名称** | 搜索与查看参考文献 |
| **主参与者** | 研究者、教师 |
| **触发事件** | 用户进入「参考文献」页面 |
| **前置条件** | 用户已打开 /references 页面 |
| **后置条件** | 用户找到目标文献并获取链接 |
| **主成功场景** | 1. 系统加载60条参考文献 <br>2. 用户选择「报告」类型筛选 <br>3. 列表显示所有报告类文献 <br>4. 用户输入「学习」关键词，按回车 <br>5. 系统匹配中英文标题，返回结果 <br>6. 用户点击某条文献 <br>7. 弹窗显示：中文标题（大）、英文原标题（小）、作者、出处、链接 <br>8. 如为URL类型，用户点击「打开链接」跳转 |
| **扩展场景** | 4a. 无匹配：显示「未找到相关文献」 |
| **业务规则** | 关键词同时搜索中英文标题和作者；链接类型（url/pdf/text）显示不同样式 |

### UC-009：用户注册（规划中）

| 项目 | 内容 |
|------|------|
| **用例编号** | UC-009 |
| **用例名称** | 新用户注册 |
| **主参与者** | 访客 |
| **触发事件** | 用户点击「注册」按钮 |
| **前置条件** | 用户未登录 |
| **后置条件** | 用户成功注册并自动登录 |
| **主成功场景** | 1. 用户点击「注册」<br>2. 弹出注册表单（姓名/邮箱/密码/角色选择）<br>3. 用户填写信息并提交 <br>4. 系统验证邮箱唯一性 <br>5. 系统创建账号，发送验证邮件 <br>6. 用户点击邮件中验证链接 <br>7. 账号激活，跳转首页 |
| **扩展场景** | 4a. 邮箱已注册：提示「该邮箱已存在」<br>3a. 字段验证失败：高亮错误字段并提示 |
| **业务规则** | 密码至少8位；角色可选教师/研究者 |
