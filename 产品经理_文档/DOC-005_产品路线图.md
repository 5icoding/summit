## 四、各阶段详细规划

### Phase 1：MVP 基础版（2026 Q1）✅ 已完成

**目标**：核心内容数字化，技术架构搭建完成

| 功能 | 状态 | 说明 |
|------|------|------|
| 萨米特素养框架展示 | ✅ | 7领域/36维度/9水平 |

| 参考课标对应 | ✅ | 语言/社会/科学 |

## 五、技术演进路线

| 阶段 | 技术重点 |
|------|---------|
| MVP | Vue3 + Express + MySQL（本地开发） |
| v1.5 | 云端部署（阿里云/腾讯云），CDN加速，HTTPS |
| v2.0 | Redis 缓存，Elasticsearch 全文检索 |
| v2.5 | 微服务拆分（用户服务/内容服务），消息队列 |
| v3.0 | 数据仓库，BI 看板，评估算法引擎 |
| v4.0 | LLM 集成（Claude API/通义千问），向量数据库 |

## 七、风险与依赖

| 风险 | 影响 | 应对 |
|------|------|------|
| 内容翻译质量 | 用户体验下降 | 建立专业审核流程，优先机器翻译+人工校对 |
| 版权问题 | 法律风险 | 联系 Summit Learning 授权，或以参考方式处理 |
| 用户增长缓慢 | 商业目标延迟 | 加大教育圈KOL合作，免费内容引流 |
| 竞争对手跟进 | 市场份额被抢 | 加速迭代，深化素养评估工具护城河 |
