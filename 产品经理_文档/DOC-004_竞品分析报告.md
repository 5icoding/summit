## 三、核心竞品深度分析

### 3.1 PARB（Performance Assessment Resource Bank）
**网址**：https://performanceassessmentresourcebank.org

| 维度 | 分析 |
|------|------|
| 定位 | 国际 PBL 绩效评估资源库，由 Stanford SCOPE 支持 |
| 目标用户 | 美国 K12 教师、课程研究者 |
| 核心功能 | 按标准/学科/年级筛选项目，下载教学材料，查看评分量规 |
| 内容规模 | 数千个 PBL/表现性评估任务 |
| 语言 | 纯英文 |
| 认证体系 | 与 Common Core、NGSS 等课程标准深度对应 |
| 商业模式 | 免费（学术机构支持） |
| 优势 | 权威性高、资源丰富、标准对应完整、PARB 已被萨米特公立学校深度使用 |
| 劣势 | 全英文无中文版、无法在国内顺畅访问、无中国课标映射、无社区互动 |
| 对我方启示 | 这是我们最直接的内容来源和参考，中文本土化是最大差异化空间 |

### 3.2 Buck Institute for Education（PBLWorks）
**网址**：https://www.pblworks.org

| 维度 | 分析 |
|------|------|
| 定位 | PBL 方法论权威机构，提供培训、资源、认证 |
| 目标用户 | 教师、学校管理者、教育机构 |
| 核心功能 | PBL 理论指南、项目设计工具包、教师培训课程 |
| 商业模式 | 培训收费、会员制 |
| 优势 | PBL 品牌认知度最高、理论体系完整、Gold Standard PBL 框架权威 |
| 劣势 | 无中文内容、无结构化评估工具、项目资源数量有限 |
| 对我方启示 | 方法论参考来源，可借鉴其 Gold Standard PBL 框架进行本土诠释 |

## 五、差异化定位分析

### 我方核心差异化优势

1. **唯一中文化萨米特素养平台**
   - PARB 拥有完整资源但无中文，本平台填补空白
   - 中文标题、中文翻译版本同步提供

2. **系统化素养框架可视化**
   - 7领域 → 36维度 → 9水平的完整层级
   - 维度与 PBL 项目的双向关联（哪些项目覆盖哪些维度）

3. **中国课标对应**
   - 维度与语言/社会/科学课标的映射关系
   - 便于教师在国内课堂直接应用

4. **完整项目包开箱即用**
   - 学生任务书（中英对照）
   - 教师指导书
   - 评分量规（Rubric）

### SWOT 分析

| | 优势（S） | 劣势（W） |
|---|---------|---------|
| **机会（O）** | 政策红利期快速抢占市场 | 内容翻译质量需持续提升 |
| **威胁（T）** | 先发优势建立用户习惯 | 大平台进入需提升壁垒 |

**S（优势）**：中文本土化、系统完整、权威来源、技术敏捷
**W（劣势）**：品牌新、资源总量少于 PARB、用户群待建立
**O（机会）**：政策驱动需求、PBL 赛道空白、国际内容本土化
**T（威胁）**：大平台跟进、版权风险、翻译质量竞争

## 六、竞争策略建议

1. **近期（0-6个月）**：以 PARB 内容的高质量中文化为护城河，快速建立内容壁垒
2. **中期（6-18个月）**：加入用户生成内容（UGC），让教师分享本土化 PBL 项目
3. **长期（18个月+）**：开发 AI 辅助 PBL 设计工具，形成技术壁垒
