## 二、产品定位

**一句话定义**：面向中国教师和教育研究者的萨米特 PBL 项目式学习资源与核心素养评估平台。

**核心价值**：
- 提供中文化的萨米特核心素养框架（7领域/36维度/9水平）
- 提供 36 个经萨米特公立学校验证的 PBL 项目完整资源包
- 提供项目与课程标准的对应关系
- 提供完整参考文献资料库（双语）

---

## 三、用户角色定义

| 角色 | 标识 | 权限范围 |
|------|------|---------|
| 访客 | Guest | 浏览首页、框架概览、项目列表摘要 |
| 注册教师 | Teacher | 全库浏览、资源下载、收藏、评论 |
| 课程研究者 | Researcher | 同上 + 高级筛选、数据导出 |
| 管理员 | Admin | 内容管理、用户管理、数据统计 |

## 五、功能需求详细说明

### 5.1 首页（HomePage）

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 统计卡片 | P0 | 展示：能力领域数、维度数、PBL项目数、参考文献数 |
| 领域快速入口 | P0 | 7个能力领域卡片，点击跳转框架页 |
| 系统简介 | P1 | 介绍萨米特素养框架与平台价值 |
| 最新内容 | P2 | 最新上线的 PBL 项目推荐 |

### 5.2 核心素养框架（FrameworkPage）

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 左侧领域导航 | P0 | 7个领域树形导航，点击切换右侧内容 |
| 维度卡片展示 | P0 | 显示维度名称、描述、所属领域 |
| 水平等级查看 | P0 | 点击维度进入详情页，查看0-8级描述 |
| 课标对应展示 | P0 | 显示该维度是否对应语言/社会/科学课标 |
| 水平步进器 | P1 | 维度详情页内滑动切换0-8级水平描述 |

### 5.3 PBL 项目库（PblPage）

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 项目列表表格 | P0 | 展示：名称(中/英)、学科、学段、时长、认证状态 |
| 学科筛选 | P0 | 语言/社科/科学/数学 单选切换 |
| 年级筛选 | P0 | 6-12年级单选 |
| 关键词搜索 | P0 | 支持中英文名称搜索，回车/按钮触发 |
| 认证筛选 | P1 | 筛选官方认证项目 |
| 项目详情弹窗 | P0 | 点击项目行弹出详情（元数据+链接） |
| 查看完整详情 | P1 | 弹窗内按钮跳转完整详情页 |

### 5.4 PBL 项目详情页（PblDetailPage）

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 项目基本信息 | P0 | 名称、学科、课程、年级、时长、认证 |
| 章节导航 | P0 | 左侧固定目录：基本信息/学生任务书/教师指导/量规/附件 |
| 内容折叠面板 | P0 | 各章节内容可展开/收起，支持全展开/全收起 |
| 内容双语展示 | P1 | 中英文标题对照展示 |

### 5.5 公开PBL项目汇总（PblOpenPage）

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 统计概览 | P0 | 总量、认证数、学科分布 |
| 多维筛选 | P0 | 学科/学段/年级/认证/关键词 |
| 项目列表 | P0 | 含PA类型、适用年级圆点、时长 |
| 维度弹窗 | P0 | 点击项目展示36个能力维度适用情况（7组分类） |
| 年级标签 | P0 | 6-12年级标签，高亮适用年级 |
| 双链接跳转 | P0 | 原始英文链接 + 中文翻译链接 |

### 5.6 参考文献（ReferencesPage）

| 功能点 | 优先级 | 描述 |
|--------|--------|------|
| 文献列表 | P0 | 序号、类型、作者、年份、中文标题、英文标题、链接类型 |
| 类型筛选 | P0 | 书/报告/文章/网站/课程标准 |
| 链接类型筛选 | P1 | URL/PDF/购书链接 |
| 关键词搜索 | P0 | 同时搜索中英文标题 + 作者 |
| 文献弹窗 | P0 | 完整信息：中文标题、英文标题、作者、出处、链接 |
| 外部链接 | P1 | URL类文献可直接点击跳转 |
| 下载状态 | P2 | 显示文献内容下载状态 |

## 六、非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 首屏加载 < 2秒，列表查询 < 500ms |
| 响应式 | 支持 PC（主）/ 平板（次），暂不要求移动端 |
| 浏览器兼容 | Chrome 90+、Edge 90+、Safari 14+ |
| 数据安全 | 用户数据加密存储，接口鉴权（规划中） |
| 可用性 | 服务可用率 ≥ 99.5% |
| SEO | 关键内容服务端渲染（规划中） |
