## 二、市场背景与规模

### 2.1 市场规模

- 中国基础教育阶段（K12）学生约 1.8 亿人，教师约 1500 万人
- 中国教育科技市场规模 2025 年预计超过 5000 亿元
- PBL/探究式学习工具细分市场处于早期，竞争格局尚未形成
- 国际学校、双语学校约 2000 所，是高意愿付费用户群

### 2.2 政策催化

| 政策 | 发布时间 | 相关影响 |
|------|---------|---------|
| 义务教育课程方案（2022版） | 2022年 | 明确"素养导向"，跨学科主题学习写入课标 |
| 双减政策 | 2021年 | 学科培训收缩，学校内素质教育需求上升 |
| 新高考改革 | 2019年起 | 综合素质评价纳入录取，研究性学习必修 |
| 教育数字化战略 | 2022年 | 推动优质教育资源数字化、共享化 |

## 三、目标用户画像

### 3.1 核心用户——一线教师

| 维度 | 描述 |
|------|------|
| 年龄 | 25-45岁 |
| 学校类型 | 公立重点校、国际学校、双语学校、创新学校 |
| 痛点 | 缺乏优质 PBL 项目模板；不知道如何评估学生素养；跨学科设计能力不足 |
| 需求 | 现成可用的项目包；清晰的评分量规；与课标对应的维度映射 |
| 使用场景 | 备课时查找参考案例；学期初选择项目；课后评估学生表现 |
| 付费意愿 | 中等（个人）/ 高（学校采购） |

### 3.2 次要用户——课程研究者与教育管理者

| 维度 | 描述 |
|------|------|
| 角色 | 教研员、课程主任、校长助理 |
| 需求 | 了解国际先进课程框架；获取系统性素养评估工具；为学校制定课程改革方案 |
| 使用场景 | 调研参考、方案撰写、校本课程开发 |
| 付费意愿 | 高（机构采购） |

### 3.3 延伸用户——学生与家长

| 维度 | 描述 |
|------|------|
| 角色 | 初中/高中学生、关注素养教育的家长 |
| 需求 | 了解自身素养水平；获取学习资源；为综合素质评价准备材料 |
| 使用场景 | 自主学习、研究性学习选题 |
| 付费意愿 | 低（个人）/ 中（家长） |

## 四、用户核心需求（Jobs to be Done）

| 用户类型 | 核心任务 | 当前解决方案 | 缺口 |
|---------|---------|------------|------|
| 教师 | 设计一个有意义的 PBL 项目 | 自行摸索/参考教材 | 无成熟模板，耗时大 |
| 教师 | 评估学生的素养表现 | 自制量表/感性判断 | 缺乏标准化工具 |
| 教研员 | 理解国际素养框架 | 查文献/读英文原著 | 中文资源匮乏 |
| 管理者 | 建立学校素养评估体系 | 外部咨询/购买课程 | 成本高，适用性差 |
| 学生 | 完成高质量的研究性学习 | 百度/教师指导 | 缺乏结构化指引 |

## 五、竞品市场分析（概览）

| 竞品 | 定位 | 优势 | 劣势 |
|------|------|------|------|
| PARB（美国） | 国际 PBL 资源库 | 资源丰富（数千个项目）、萨米特背书 | 全英文、无中文、无法访问 |
| Buck Institute（BIE） | PBL 方法论 | 理论体系完整 | 无系统化资源库，无评估工具 |
| 好未来/学而思 | 综合教育平台 | 用户规模大 | 非 PBL 专注，素养体系不成熟 |
| 一起学/教学通 | 教师备课工具 | 覆盖面广 | 无 PBL 专项，无素养框架 |
| 探月学院 | 创新学校 | PBL 实践丰富 | 仅服务自有学校，不对外 |
| 本平台 | 中文PBL资源+素养评估 | 中文、本土化、系统化 | 品牌新、用户规模待建立 |


## 七、市场进入策略

### 阶段一：垂直深耕（0-6个月）
- 聚焦国际学校、创新学校教师群体
- 通过教育博主、教研活动免费推广
- 建立种子用户社群（微信群/公众号）

### 阶段二：横向扩展（6-18个月）
- 向公立重点校渗透
- 与教研部门合作，进入官方教研体系
- 开发教师培训课程，形成服务闭环

### 阶段三：平台化（18-36个月）
- 允许教师上传自创 PBL 项目
- 建立素养评估 SaaS 工具
- 拓展至职业教育、高等教育
